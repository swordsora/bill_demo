# Invoice Program PWA

هذا تطبيق فواتير عربي يعمل كـ PWA باستخدام HTML وCSS وJavaScript فقط. يمكن رفع محتويات المجلد إلى GitHub Pages أو Netlify أو أي خادم static يدعم HTTPS. بعد أول فتح، يخزن Service Worker ملفات التطبيق والمنتجات ليعمل التطبيق دون اتصال.

## التشغيل

ارفع جميع الملفات الموجودة في المجلد نفسه، خصوصًا `index.html` و`app.js` و`style.css` و`manifest.json` و`sw.js` و`products.json` و`customers.json` و`customer_history.json` و`logo.png`. افتح الرابط في Chrome أو Edge، ثم اختر تثبيت التطبيق من زر التثبيت أو من قائمة المتصفح.

## الوظائف الحالية

يحتوي التطبيق على بيانات المنتجات والعملاء وسجل مشتريات العملاء. يمكن كتابة أي جزء من اسم المنتج أو كوده داخل نفس الحقل، فتظهر اقتراحات مباشرة. عند الاختيار يظهر الكود والسعر حسب مستخدم 2 أو مستخدم 3، ويمكن تحديد الكمية وإضافة المنتجات وتعديلها أو حذفها. يحسب التطبيق إجمالي الفاتورة، ويحفظ الفواتير محليًا، ويتيح الطباعة والنسخ الاحتياطي والاسترداد وتصدير أو حذف عدة فواتير محددة.

## تعديل الأسعار المتقدم

يوجد زر الترس بجوار كل منتج داخل قائمة الفاتورة. تعديل السعر محمي بكلمة مرور التعديل المتقدم، وتسمح الحدود الافتراضية بتغيير السعر في نطاق 30% زيادة أو نقصان. تعديل السعر خارج النطاق يحتاج كلمة المرور الإضافية. عند إدخال كلمة مرور غير صحيحة تُقفل الخاصية حتى إدخال كلمة التفعيل.

## الاختصارات

`Ctrl+S` لحفظ الفاتورة، `Ctrl+P` للطباعة، `Ctrl+N` لفاتورة جديدة، و`Enter` بعد إدخال الكمية لإضافة المنتج.

## تخزين ملفات قاعدة البيانات
عند اختيار مجلد قاعدة البيانات أو ملفاته، يحفظ التطبيق الملفات المعتمدة نفسها مع مساراتها في IndexedDB داخل المتصفح. عند اختيار مجلد جديد تُستبدل المجموعة السابقة بالكامل، وعند إعادة فتح التطبيق تُستعاد المجموعة الأخيرة تلقائيًا. هذا يسمح بتغيير مسار الملفات دون الاعتماد على مسار نظام ملفات دائم أو صلاحيات قد تنتهي بعد إغلاق المتصفح.

## قاعدة البيانات المركزية عبر Supabase
تم استبدال الخادم المركزي السابق بطلبات إلى Supabase Edge Function باسم `central-api`. قبل النشر، افتح `central-config.js` وضع `supabaseUrl` و`anonKey` لمشروع Supabase، ثم أنشئ Edge Function تستقبل جسمًا بالصيغة التالية وتنفذ المسار المطلوب:

```json
{
  "path": "/login",
  "method": "POST",
  "body": { "username": "...", "password": "..." }
}
```

يجب أن تعيد الدالة JSON متوافقًا مع الاستجابات التي يتوقعها التطبيق للمسارات `/login` و`/heartbeat` و`/qr-login` و`/devices` و`/devices/action` و`/devices/block-self` و`/devices/unlock` و`/accounts/sync` و`/login-attempts` و`/invoices`. لا تضع `service_role key` داخل ملفات الواجهة؛ استخدمه داخل Edge Function فقط. يوجد مخطط قاعدة البيانات المبدئي في `supabase/schema.sql`.

## ملاحظة قاعدة البيانات
المتصفح لا يفتح ملف Access MDB مباشرة. لذلك يقرأ التطبيق ملف `Invoice Program.mdb` محليًا عند اختياره، ويحوّل جداول الأصناف والعملاء إلى بيانات التطبيق. تبقى البيانات والفواتير المحلية مرتبطة بالمتصفح والجهاز؛ استخدم زر النسخ الاحتياطي بانتظام.
